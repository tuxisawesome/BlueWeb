=====Install======
 1) Download and install TI-Connect CE or TILP if you don't already have connectivity software.
 
 2) Transfer the latest C libraries to your calculator; you can find them at this link:
 	 https://github.com/CE-Programming/libraries/releases/latest
 
 3) Transfer the file in this folder: DKONG.8xp

=======Play=======
 To run the game, select "Asm(" from the catalog, then press [prgm] and select "FLAPPYB".
 You should see Asm(prgmFLAPPYB on your screen.
 Then press [enter].

=====Controls=====
 Press any key to start and move the bird
 [Clear]  - exit the game
